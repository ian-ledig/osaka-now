# Security

The app reads public web pages and opens links in your browser, so a mistake in how fetched data is handled could matter.

If you find a problem of that kind, please don't open a public issue. Use [Report a vulnerability](https://github.com/ian-ledig/osaka-now/security/advisories/new) to report it privately, with the steps to reproduce it and the version you used.

Only the latest release gets fixes.
